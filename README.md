# Контейнерная платформа

## Общая информация

Курсовой проект по дисциплине «Основы программирования и алгоритмизации».

**Индивидуальный вариант:** 7.

## Назначение программы

Программа предназначена для обработки сообщений о состоянии контейнерных узлов, выявления дубликатов, архивации уникальных записей и вывода статистики.

## Формат входного сообщения

`часы:минуты node containers restarts`

## Основные возможности

- Приём сообщений о состоянии контейнерных узлов.
- Проверка сообщений на дублирование.
- Подсчёт количества полученных сообщений.
- Подсчёт отброшенных дубликатов.
- Архивация записей.
- Вывод статистики.


## Статус проекта

Разработка начата. Реализация основных функций находится в процессе.
